Playtask:Gamified Life 隐私政策
生效日期：2026 年 5 月 28 日
1. 引言
Playtask:Gamified Life（以下简称 “本应用”）尊重并保护所有用户的隐私。本隐私政策说明了我们如何处理与你相关的信息，仅适用于本应用在 macOS 平台上的使用场景。
2. 信息收集
本应用不会主动收集、上传或向第三方共享任何个人身份信息或用户数据：
所有任务、计划、习惯记录等数据，仅存储在你的本地设备上，不会同步到任何外部服务器；
本应用不收集你的姓名、邮箱、手机号、位置信息、设备唯一标识符等个人信息；
本应用不收集用户行为数据、使用日志，也不用于任何数据分析或广告推送。
3. 信息存储
所有由你创建的任务、进度和设置数据，仅保存在你的 macOS 设备本地；
数据的删除与修改仅由你在设备上直接操作完成，我们无法访问或获取这些数据。
4. 第三方服务
本应用不集成任何第三方服务、SDK 或广告组件，因此不会向任何第三方传输你的数据。
5. 未成年人保护
本应用无年龄限制，所有功能均为本地任务管理工具，不包含任何不适宜未成年人的内容，也不收集未成年人的任何信息。
6. 隐私政策更新
我们可能会不时更新本隐私政策。如有重大变更，我们会在本页面发布更新后的版本，并注明生效日期。
